# 基于多层感知机的多层介质薄膜光谱预测与辅助设计

> MLP-Based Spectral Prediction and Assisted Design of Multilayer Dielectric Thin Films

## 项目简介

本项目实现了一个基于多层感知机 (MLP) 的代理模型，用于快速预测多层介质薄膜的光谱反射率，并利用该模型辅助薄膜设计筛选。

*核心流程：*

1. *传输矩阵法 (TMM)* 生成 5000 组四层介质膜 (H/L/H/L) 的厚度-光谱数据
2. *MLP 代理模型* 学习膜厚 → 反射率光谱的映射关系 (4 → 128 → 128 → 64 → 41)
3. *学习曲线实验* 对比不同训练规模 (500/1000/2000/4000) 下的模型精度
4. *辅助设计筛选* 从 10000 个随机候选中，MLP 快速筛选 Top-10，TMM 精确验证得到最终 Top-5

## 运行环境

- *MATLAB* (需安装 Deep Learning Toolbox)
- 无需额外依赖，所有代码从零实现（含 TMM、Adam 优化器、早停法）

## 运行方法

```matlab
% 在 MATLAB 中打开项目目录，直接运行主脚本
run('optical_thin.m')
```

脚本将自动完成：
- 数据集生成与划分
- 四组不同训练规模的 MLP 训练
- 学习曲线可视化
- 10000 候选薄膜的 MLP 筛选 + TMM 验证
- 最终 Top-5 设计的表格与光谱图输出

## 关键参数

| 参数 | 值 |
|------|-----|
| 膜系结构 | 4 层 (H/L/H/L) |
| 高折射率 n_H | 2.30 |
| 低折射率 n_L | 1.45 |
| 波长范围 | 400–800 nm (步长 10 nm) |
| 膜厚范围 | 40–180 nm |
| 目标波长 | 560 nm |
| MLP 结构 | 4 → 128 → 128 → 64 → 41 |
| 激活函数 | ReLU |
| 优化器 | Adam (lr=0.001) |
| 训练轮次 | 1000 epochs (早停 patience=50) |

## 主要结果

- 训练集 N=4000 时，测试集 MAE = 0.81%，R² = 0.9958
- MLP 筛选速度约 3.6×10⁵ 候选/秒
- TMM 验证通过率 100%（误差容限 2%）
